# Jobs

A *job* produces a printable image on demand or on a schedule. Each job is a function
`fn(params: dict, ctx: JobContext) -> PIL.Image` returning a mode-`"1"` image exactly 384 px wide.
`params` comes from the HTTP request or schedule and may be empty — every job has defaults.
`ctx.http` is a `requests.Session`, `ctx.setting(key)` reads settings (`home_lat`, `home_lon`,
`timezone`, `todo_file`, …) and `ctx.now()` is the clock.

## Adding a job module

1. Create `minixprint/jobs/<anything>.py` (no registration anywhere else).
2. Export a module-level mapping and build images with `minixprint.render` helpers:

```python
from ..render import render_text, rule, stack

def hello(params, ctx):
    return stack(render_text(params.get("name", "world"), size=32, align="center"), rule())

JOBS = {"demo.hello": hello}
```

3. `discover()` imports every module in the package and merges the `JOBS` dicts; duplicate names
   raise. Modules starting with `_` (e.g. `_common.py`) are helpers and may omit `JOBS`.
4. Keep jobs failure-tolerant: network calls get timeouts, and a missing data source should degrade
   the output rather than raise. Add a test and a sample in `scripts/make_fun_samples.py`.
5. Ship static data under `minixprint/jobs/data/` (listed in `package-data` in `pyproject.toml`).

Seeded jobs use `_common.rng(params, ctx)`: `params.seed` if given, otherwise today's date in the
configured timezone, so the same day yields the same result.

## Built-in fun jobs

Regenerate samples with `python scripts/make_fun_samples.py` (network mocked by
`tests/fixtures/open-meteo.json`).

### `puzzle.sudoku`
| param | default | meaning |
| --- | --- | --- |
| `difficulty` | `medium` | `easy` (~40 clues), `medium` (~32), `hard` (~26) |
| `seed` | date | any string/number |
| `with_solution` | `false` | append a small solution grid after a dashed rule |

Generated by randomised backtracking, then clues are removed one at a time while the puzzle keeps a
**unique** solution (checked with a solution counter). ![sudoku](samples/puzzle.sudoku.png)

### `puzzle.maze`
`size` (cells per side, clamped to 15..41 and forced odd, default 25), `seed`. Recursive-backtracker
perfect maze, 2-px walls, square; `S` marks the entrance (top-left), `E` the exit (bottom-right).
![maze](samples/puzzle.maze.png)

### `puzzle.wordsearch`
`words` (list of strings) or `theme` (`aviation|space|kitchen|animals`, default picked by seed),
`seed`. 12×12 grid, words placed in all 8 directions; the word list is printed underneath.
![wordsearch](samples/puzzle.wordsearch.png)

### `fortune`
`seed`. One line from `minixprint/jobs/data/fortunes.txt` (70 original/proverbial one-liners; add
lines freely, `#` comments allowed), centred between double rules. ![fortune](samples/fortune.png)

### `morning`
The breakfast docket. `sections` (subset/order of `date, weather, todos, notes, fortune`), `todos`
(list of str), `notes` (str or list), `seed`. Setting `todo_file` supplies todos (one per line) when
`todos` is absent. Each section fails independently — offline you just lose the weather.
Weather: [Open-Meteo](https://open-meteo.com) (no key) at `home_lat/home_lon/timezone`, WMO codes
mapped to text plus a 24-px glyph. ![morning](samples/morning.png)

### `system.status`
No params. Hostname, OS, time, uptime, load, free disk, LAN IP, and the tailnet IP when
`tailscale ip -4` works. Pi health slip. ![system](samples/system.status.png)
